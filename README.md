# 大腸鏡檢查流程 3D 互動動畫

以 three.js 製作的衛教動畫，帶你從腸道準備、鎮靜擺位、插入、抵達盲腸、退鏡觀察，到息肉切除與恢復，完整走過 10 個步驟。

- 線上觀看：https://show15820-alt.github.io/colonoscopy-3d/
- 右上角為內視鏡即時影像；下方字幕說明每個階段。
- 視角：環繞全景、腸道透視、內視鏡畫面、自由視角。

## 快捷鍵
| 按鍵 | 功能 |
|---|---|
| 1–9、0 | 跳到第 1–10 步 |
| 空白鍵 | 暫停／播放 |
| N / B | 下一步／上一步 |
| O / C / E / F | 環繞全景／腸道透視／內視鏡畫面／自由視角 |
| [ / ] | 調整速度 |
| H | 隱藏介面 |
| R | 錄製影片 |

> 本動畫為衛教示意，不能取代醫師的專業說明。
